# Базове SEO

## Meta-теги
- **Title**: Налаштування унікальних title для основних типів сторінок:
  - Головна
  - Категорія
  - Картка товару
  - Блог (список публікацій)
  - Окрема публікація блогу
- **Description**: Налаштування унікальних description для основних типів сторінок

## Open Graph теги
- Встановлення базових Open Graph (OG) тегів для коректного прев'ю посилань:
  - og:title
  - og:description
  - og:image (зображення для прев'ю)
  - og:url
  - og:type
- Застосовується до основних типів сторінок

## Технічна підготовка
- **robots.txt**: Створення файлу robots.txt для інструктування пошукових ботів
- **sitemap.xml**: Створення карти сайту для пошукових систем
- Налаштування структурованих даних (schema.org) за необхідності
- Технічна підготовка всіх сторінок до коректної індексації пошуковими системами Google, Yandex, Bing

## Що НЕ входить
- Написання SEO-оптимізованого контенту
- Пошук та збір семантичного ядра
- Написання статей для блогу
- Закупівля посилань
- Будь-які гарантії позицій у пошукових системах
- Активне SEO-просування (це робить окремий фахівець)
