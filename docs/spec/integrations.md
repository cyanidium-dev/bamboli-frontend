# Інтеграції

## KeyCRM
- **Мета**: Автоматичне передання нових замовлень до системи управління відносинами з клієнтами
- **Що передається**:
  - Контактні дані покупця (ім'я, телефон, email)
  - Перелік товарів у замовленні
  - Кількість кожного товару
  - Підсумкова сума замовлення
  - Вибраний способ доставки (Нова Пошта, тощо)
  - Вибраний спосіб оплати (MonoPay, LiqPay)
  - Статус оплати (Оплачено / Не оплачено)
- **Коли передається**: Одразу після оформлення замовлення на сайті

## Онлайн-оплата
- **Підтримувані системи**: MonoPay або LiqPay (за вибором Замовника)
- **Функціональність**:
  - Перенаправлення на сторінку платіжної системи
  - Обробка callback з платіжної системи
  - Передача статусу оплати до KeyCRM
- **Умови**: Акаунт Замовника повинен бути затвердженим платіжною системою

## Нова Пошта
- **Мета**: Отримання та показ переліку доступних варіантів доставки
- **Функціональність**:
  - Отримання переліку відділень Нової Пошти
  - Отримання переліку поштоматів Нової Пошти
  - Показ цих варіантів при оформленні замовлення
  - Збереження вибраного відділення/поштомату в замовленні
- **Що НЕ входить**:
  - Створення відправлень
  - Створення експрес-накладних
  - Генерування ТТН (товарно-транспортної накладної)
  - Ці операції роблять вручну через кабінет Нової Пошти

## Google Tag Manager (GTM)
- **Мета**: Встановлення контейнера для аналітики та рекламних кампаній
- **Функціональність**:
  - Встановлення GTM контейнера, наданого Замовником
  - Базова підготовка сайту до роботи з GTM
- **Що НЕ входить**:
  - Налаштування рекламних кампаній
  - Налаштування аналітичних подій та їх відстеження
  - Створення звітів
  - Ці завдання виконує фахівець з рекламі / GTM, а не розробник

## Домен
- **Мета**: Підключення вашого домену до сайту
- **Функціональність**:
  - Базове технічне налаштування DNS записів
  - Налаштування SSL сертифіката (якщо потрібно)
- **Умова**: Доступ до DNS налаштувань домену надає Замовник
