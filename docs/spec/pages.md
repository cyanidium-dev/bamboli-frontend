# Структура сторінок сайту

## Головна
- Бренд (контент про магазин)
- Категорії (навігація по основних напрямах)
- Переваги магазину
- Добірки товарів (добірка, добірка і т.д.)
- Промо-блоки (акційні оголошення)

## Каталог
- Список всіх категорій
- Сортування товарів
- Вивід товарів з фільтрацією

## Категорія
- Окрема сторінка для кожної категорії
- Показує тільки товари вибраної категорії
- Сортування та фільтрацію в межах категорії

## Картка товару
- Фото товару (основне та галерея)
- Назва та опис
- Ціна
- Характеристики (розміри, матеріали, вік і т.д.)
- Статус наявності
- Кнопка додавання до кошика
- Кнопка «Обране» (без авторизації, збереження в localStorage)

## Кошик
- Склад замовлення (список товарів)
- Можливість змінити кількість товарів
- Можливість видалити товари
- Розрахунок підсумкової суми

## Оформлення замовлення
- Введення контактних даних (ім'я, телефон, email)
- Вибір способу доставки (Нова Пошта — відділення або поштомат)
- Вибір способу оплати (MonoPay або LiqPay)
- Передача замовлення до KeyCRM
- Відправка імейлу клієнту після оформлення

## Про нас
- Інформація про магазин/бренд
- Контактні дані
- Реквізити

## Доставка
- Умови доставки
- Способи доставки
- Умови повернення
- Контакти для питань

## Блог
- Список матеріалів (лента публікацій)
- Окрема сторінка для кожної публікації з можливістю читання повного тексту

## Службові сторінки
- 404 (сторінка не знайдена)
- 500 (помилка сервера)
- Інші технічні сторінки за необхідності
