# Функціональність магазину

## Адаптивність
- Адаптивне відображення на смартфонах (мобільна версія)
- Адаптивне відображення на планшетах (планшетна версія)
- Адаптивне відображення на комп'ютерах (десктопна версія)

## Каталог товарів
- Організація товарів за категоріями
- Вивід товарів з основною інформацією (фото, назва, ціна)
- Фото товарів з можливістю переглядання
- Характеристики товару (розмір, матеріал, вік, тощо)
- Статус наявності (в наявності / нема в наявності / під замовлення)
- Сортування товарів (за популярністю, ціною, новизною)

## Плашки для товарів
- **«Знижка»** — вмикається для окремих товарів через адмін-панель (Sanity)
- **«Топ»** — вмикається для окремих товарів через адмін-панель (Sanity)
- Ці плашки мають на меті привернути увагу до популярних або акційних товарів

## Кошик
- Додавання товарів до кошика з картки товару
- Видалення товарів з кошика
- Зміна кількості товарів (збільшення/зменшення)
- Автоматичний розрахунок підсумкової суми

## Функція «Обране»
- Додавання товарів до обраного без необхідності авторизації
- **Зберігання**: локально в браузері користувача через **localStorage**
- **Обмеження**: 
  - Обрані товари не синхронізуються між пристроями
  - Список може не зберегтися після очищення даних браузера
  - Це нормальна поведінка, не помилка

## Оформлення замовлення
- Введення контактних даних (ім'я, телефон, email)
- Вибір способу доставки та конкретного відділення/поштомату Нової Пошти
- Вибір способу оплати (MonoPay або LiqPay за вибором)
- Валідація всіх полів перед передачею
- Передача замовлення до KeyCRM з усіма даними

## Статуси замовлення в CRM
- При успішній оплаті: замовлення надходить в CRM зі статусом **«Оплачено»**
- При помилці платежу: замовлення надходить в CRM зі статусом **«Не оплачено»** (щоб менеджер міг про це дізнатися й потім звернутися до клієнта)

## Відправка email
- Після успішного оформлення замовлення клієнту надсилається **email-підтвердження** з деталями замовлення
