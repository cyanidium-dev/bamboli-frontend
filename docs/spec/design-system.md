# Дизайн-система Bamboli

Це зведення візуальних правил, які вже реалізовані в коді. **Джерело істини — код**:
токени й утиліти в [`src/app/globals.css`](../../src/app/globals.css), спільні компоненти в
`src/components/shared`. Якщо документ і код розходяться, вірити треба коду, а документ оновити.

Характер: спокійний, «дорослий» мінімалізм. Тепла нейтральна палітра, яка не конкурує з
фотографією, шрифт один, кути прямі, акцент рідкісний.

---

## 1. Кольори

Задані в `@theme inline` як Tailwind-токени (`bg-ink`, `text-muted`, `border-line` тощо).

| Токен | HEX | Призначення |
|-------|-----|-------------|
| `bg` | `#ffffff` | Фон сторінки, текст на темному |
| `surface` | `#ffffff` | Поля форм, картки |
| `mist` | `#f5f4f2` | Світлий акцентний фон секцій |
| `sand` | `#dcd5cc` | Глибший фон секцій, підкладка під фото товару |
| `line` | `#e5dfd6` | Тонкі межі, розділювачі, рамки полів |
| `ink` | `#171614` | Основний текст, головні кнопки, темні секції |
| `muted` | `#8c877f` | Другорядний текст, підписи, плейсхолдери |
| `clay` | `#a8624a` | Єдиний акцент: знижка, стара ціна, помилки валідації |

Правила:
- Чисто чорного немає, чорним є `ink`.
- `clay` використовуємо точково. Не робимо ним великі площини чи звичайні кнопки.
- Виділення тексту: фон `ink`, текст `bg`.

## 2. Типографіка

Шрифт один: **Montserrat** (латиниця + кирилиця, `display: swap`), підключений у
`src/app/layout.tsx` через `next/font`. Змінна `--font-montserrat`, токен `font-sans`
(успадковується від `body`, тому окремо клас шрифту ставити не потрібно).

База (`body`): **14px / line-height 1.3**, `antialiased`, колір `ink`.

Усі `h1`–`h6` глобально в **caps**. Кольори тексту: основний `ink`, другорядний `muted`.
Жирність: 700 — заголовки й назви, 500 — підзаголовки, 400 — решта.

### Шкала (значення взяті з головної сторінки)

| Роль | Утиліта / клас | Розмір (mobile → sm → lg) | Жирність | Line-height | Трекінг | Колір |
|------|----------------|---------------------------|----------|-------------|---------|-------|
| **H1** (внутрішні сторінки) | `u-display` | 28 → 34 → 40 px | 700 | 1.1 | −0.01em | `ink` |
| **H1** (hero головної) | `u-display` | 36 → 48 → 48 px | 700 | 1.05 | −0.01em | `ink` (на фото білий) |
| **H2** (заголовок секції) | `u-display` | 20 → 28 → 34 px | 700 | 1.1 | −0.01em | `ink` |
| **H3 / назва в картці** | `u-label font-bold` | 10 px | 700 | 1.2 | 0.18em | `ink` |
| **Підзаголовок** (H3 у блоці переваг) | `u-label u-subheading` | 10 px | 500 | 1.2 | 0.18em | `ink` |
| **Лід / цитата** | `u-subheading` | 16 → 20 px (lg) | 500 (у цитаті `font-normal`) | 1.2 | 0 | `muted` |
| **Основний текст** (абзац під заголовком) | — | 13 px | 400 | `leading-relaxed` (1.625) | 0 | `muted` |
| **Дрібний текст** (метадані, опис у плитці) | — | 11–12 px | 400 | за замовчуванням (1.3) | 0 | `muted` |
| **Мікро-підпис** (eyebrow над H2, кнопки, мета-рядки) | `u-label` | 10 px | 400 | 1.2 | 0.18em, caps | `muted` над H2, інакше `ink` |
| **Питання FAQ** | — | 15 px | 400 | `leading-snug` (1.375) | 0 | `ink`, hover `clay` |
| **Ціна** | — | 12 px, `tabular-nums` | 400 | 1.3 | 0 | `ink`, зі знижкою `clay` |

Правила:
- Сторінка «Про нас»: заголовок hero — `<h1 className="u-h2">`: семантично H1, візуально як заголовок секції (20 / 28 / 34).
- Виняток: заголовок на фото-банері `ToysCollection` — `u-display text-[26px] leading-[1.15]` (вузька картка, 34px завеликий).
- Один розмір H2 на всьому сайті: **20 / 28 / 34**. Варіант 30 / 36 (зараз у `ContactSection` і `VyshyvankaSpotlight`) — відхилення, його треба привести до стандарту.
- Абзац під H2: `13px`, `leading-relaxed`, `text-muted`, `max-w` 340–480 px (стандарт 380 px, у вузьких блоках 340 px).
- Розміри 10 / 11 / 12 / 13 / 14 / 15 — уся допустима шкала для тексту. Інші (9, 16 поза лідом, 26 тощо) не вводимо, крім промо-акцентів за окремим рішенням.
- Помилка валідації: 11 px, `clay`.
- Формат ціни: **1 200 грн** (нерозривний пробіл як роздільник тисяч, «грн» після числа).

### Утиліти в `globals.css`

Кожна роль самодостатня: розмір, жирність, line-height, трекінг і caps задані в класі, у розмітці лише вибираємо роль.

| Утиліта | Що задає |
|---------|----------|
| `.u-h1` | H1 внутрішніх сторінок: 28 → 34 → 40, 700, 1.1 |
| `.u-h1-hero` | H1 hero: 36 → 48, 700, 1.05 |
| `.u-h2` | H2 секції: 20 → 28 → 34, 700, 1.1 |
| `.u-h3` | Назва в картці: 10px, 700, 0.18em, caps |
| `.u-lead` | Лід і цитати: 16 → 20 (lg), 500, 1.2, `muted` |
| `.u-body` | Абзац: 13px, 1.625, `muted` |
| `.u-small` / `.u-caption` | 12px / 11px, `muted` |
| `.u-label` | Мікро-підпис: 10px, 0.18em, caps, 1.2 |
| `.u-display`, `.u-subheading` | Старі базові: 700 caps / 500. Лишаються для сумісності, у нових місцях беремо ролі вище |

## Токени в `globals.css`

| Токен | Значення | Утиліти |
|-------|----------|---------|
| `--section-gap` | 3.5rem → 4rem (md) → 5rem (lg) | `.u-section-mt`, `.u-section-pt` |
| `--section-pad` | 3rem → 3.5rem (md) → 5rem (lg) | `.u-section-py`, `.u-section-pb` |
| `--ease-soft` | `cubic-bezier(0.22, 1, 0.36, 1)` | Tailwind `ease-soft` |
| `--duration-fast / base / slow` | 300 / 500 / 800ms | `duration-(--duration-fast)` |
| `--z-sticky / header / backdrop / modal / toast` | 40 / 80 / 90 / 100 / 120 | `.z-sticky`, `.z-header`, `.z-backdrop`, `.z-modal`, `.z-toast` |

Усередині компонента для локального шарування (бейдж над фото) лишаються `z-10` / `z-20`; усе, що конкурує з іншими компонентами, бере токен.

## 3. Сітка, відступи, секції

- **Контейнер** (`ui/Container`): `max-w-[1280px]`, бічні поля `px-5`, від `lg` — `px-10`.
- **Брейкпоінти**: стандартні Tailwind + додатковий `xs` = 26rem (416px).
- Сітка товарів: фото 3:4, `sizes` для `next/image`: 50vw (до 767px) → 33vw → 25vw.

### Секція: два стандартні типи

Кроки відступів: **mobile 56 / md 64 / lg 80 px** для проміжку між секціями та **48 / 56 / 80 px** для внутрішніх відступів кольорової секції.

| Тип | Класи | Коли |
|-----|-------|------|
| **Біла секція** (без фону) | `pt-14 md:pt-16 lg:pt-20` | Відступ тільки зверху, наступна секція сама додає свій. Приклади: каруселі товарів, `ToysCollection`, `Faq` |
| **Кольорова секція** (`bg-mist` / `bg-sand`) | `mt-14 md:mt-16 lg:mt-20` + `py-12 md:py-14 lg:py-20` | Зовнішній відступ відділяє від попередньої секції, внутрішній дає повітря всередині фону. Приклади: `Benefits`, `VyshyvankaSpotlight`, `InstagramReels`, `ContactSection` |
| **Кольорова секція, що йде після блока іншого кольору** (`spacing="flush"`) | `py-12 md:py-14 lg:py-20` (без `mt`) |
| **Кольорова секція, що продовжує блок того ж кольору** (`spacing="continued"`) | `pb-12 md:pb-14 lg:pb-20` | Коли фон логічно продовжує блок вище. Приклади: `CategoryStrip`, `Reviews` |

Чергування фонів: `bg` → `mist` → `bg` → `sand`. Дві секції підряд з однаковим кольором фону не ставимо.
Секція, на яку ведуть якорі, додає `scroll-mt-[90px] lg:scroll-mt-[100px]` (висота хедера).

### Внутрішній ритм секції (всередині контейнера)

| Проміжок | Значення |
|----------|----------|
| eyebrow (`u-label`) → H2 | `mb-3` (12px) |
| H2 → абзац | `mt-5` (20px) |
| Абзац → кнопка | `mt-9` (36px) |
| Сітка / карусель → кнопка | `mt-12` (48px) |
| H1 hero → кнопка | `mt-7` (28px), виняток тільки для hero |
| Блок заголовка → контент (сітка, карусель) | `mb-8`, від `lg` — `mb-12` |
| Заголовок H3 → текст у картці | `mt-3` (назва → опис `mt-1.5`) |
| Цитата: відступ від тексту | `mt-8`, ліва межа `border-l border-clay pl-5` |
| Проміжок між кнопками в ряду | `gap-3` |

### Кнопки: розміри

| Розмір | Класи | Де |
|--------|-------|----|
| Стандарт | `px-7 py-4` | CTA в секціях, hero |
| Компактний | `px-6 py-3.5` | Пара кнопок поруч (`InstagramReels`), форми, повна ширина на mobile |

Обидва розміри: `u-label`, 1px рамка, hover інвертує колір за 300ms.

## 4. Форма елементів

- **Кути прямі**. `rounded-full` використовується тільки для круглих елементів: лічильник кошика, кольорові свотчі.
- Рамки: 1px, `border-line` для нейтральних, `border-ink` для активних та акцентних.
- Тіней немає. Глибину створюють фон (`mist`/`sand`) і межі.
- Іконки: `ui/Icons.tsx` та `icons/TagIcon.tsx`.

## 5. Компоненти

### Кнопки
Основна (заповнена), за замовчуванням для CTA:
```
u-label border border-ink bg-ink px-7 py-4 text-bg transition duration-300
hover:bg-transparent hover:text-ink
```
Варіації тільки за шириною й відступами: `w-full`, `px-6`, `lg:w-auto lg:px-14`. Ховер інвертує
кнопку в контурну.

### Посилання
- Підкреслене з підписом: `u-label border-b border-ink pb-1 transition hover:opacity-60` (наприклад, «Дивитись усе»).
- `.u-underline`: підкреслення росте зліва при hover/focus-visible (450ms, `cubic-bezier(0.22, 1, 0.36, 1)`).

### Поля форм
`ContactForm`:
```
w-full border border-line bg-surface px-4 py-3.5 text-[14px] outline-none transition
placeholder:text-muted/70 focus:border-ink
```
- Підпис над полем: `u-label mb-2 block text-muted`.
- Помилка: `border-clay` + текст 11px `text-clay` під полем, `aria-invalid`.

### Картка товару (`productCard`)
- Фото 3:4 на підкладці `sand`, друге фото проявляється при hover (crossfade 550ms), легкий zoom `1.025` (800ms). Hover-ефекти тільки на `lg`.
- Бейджі (`Новинка`, `Топ`) — `u-label` на `bg/90`. Знижка (`Знижка` або `−N%`) — `bg-clay text-bg`.
- Кнопка «Обране» у правому верхньому куті, бейджі — у лівому.
- Фіксований рядок свотчів висотою 14px, щоб заголовки на всіх картках стояли на одному рівні.
- Назва: `u-label`, `font-bold`, до 2 рядків. Ціна по центру, стара ціна й нова — `clay`.

### Заголовок секції (`ui/SectionHeading`)
Необов’язковий підпис (`u-label text-muted`) + заголовок `u-display` + необов’язкове посилання праворуч, яке лишається в одному рядку із заголовком на всіх ширинах.

### Базові компоненти (`src/components/shared/ui`)

| Компонент | Призначення |
|-----------|-------------|
| `Section` | Обгортка секції: `tone` (`white`, `mist`, `sand`), `spacing` (`default`, `flush`, `continued`), `id` (додає `scroll-mt` під хедер). Відступи бере з токенів |
| `Button` | `variant`: `filled`, `outline`, `light` (на фото), `text-link`; `size`: `md` (`px-7 py-4`), `sm` (`px-6 py-3.5`); `fullWidth`; з `href` рендерить `Link` (для `http` відкриває нову вкладку, `tel:`/`mailto:` звичайний `<a>`). Зовнішні відступи задає батьківський елемент |
| `SectionHeading` | Eyebrow + H2 + необов’язковий абзац + посилання справа; `align`, `className="mb-0"` для скасування нижнього відступу |
| `PageHeading` | H1 внутрішніх сторінок (`u-h1`) з необов’язковими eyebrow й абзацом |
| `Field`, `fieldControl()` | Label + поле + помилка. `on="color"` (світла рамка `line`) або `on="white"` (`ink/40`, підпис `ink`); `floatingError` виносить помилку з потоку |

### Інші спільні компоненти
`Header`, `Footer`, `CartDrawer`, `SearchOverlay`, `Faq`, `SizeChart`, `ContactForm`,
`ScrollRow`, `ScrollTabs`, `Backdrop`, `Logo`, `InViewVideo`, `Reveal`.

## 6. Рух

- **Easing за замовчуванням**: `cubic-bezier(0.22, 1, 0.36, 1)` (м’яке гальмування, без відскоку).
- `Reveal` (motion): поява знизу на 14px, 700ms, один раз, `amount: 0.25`.
- Переходи інтерфейсу: 300ms (кнопки), 450ms (підкреслення), 550–800ms (фото).
- Hero: `hero-zoom` (1.05 → 1, 2.5s) і `hero-progress` (лінійний прогрес слайдера).
- **`prefers-reduced-motion`**: усі анімації й переходи скорочуються до ~0, `hero-zoom` вимикається. Нові анімації мають це поважати.

## 7. Доступність і взаємодія

- `cursor: pointer` для активних кнопок, `summary`, `label[for]`. `not-allowed` для `disabled`.
- Фокус: `focus-visible` є у підкресленні. Для нових інтерактивних елементів треба зберігати видимий стан фокусу.
- Помилки форм: `aria-invalid` + колір і текст, не лише колір.
- Горизонтальний скрол не допускається: `html, body { max-width: 100vw; overflow-x: clip }`. Для прихованого скролбару в рядках — утиліта `.no-scrollbar`.

## 8. Чого дотримуватись при додаванні UI

1. Спершу використовувати наявні токени й утиліти (`u-label`, `u-display`, кольори з палітри), нових HEX-значень у компонентах не вводити.
2. Нова повторювана утиліта — у `@layer components` у `globals.css`, а не копіювання довгого рядка класів.
3. Мова інтерфейсу — тільки українська.
4. Мобільний екран перший: `px-5`, вертикальний стек, hover-ефекти тільки на `lg`.

## 9. Відомі прогалини та розбіжності з цим стандартом

- Відступ «абзац → кнопка» поза головною плаває між `mt-9`, `mt-10` і `mt-12` (виправляється в пакетах 3.2–3.6).
- Ширина абзацу під H2 плаває: 340 / 380 / 480 px.
- `Section`, `Button`, `PageHeading`, `Field` створені, але сторінки ще не переведені на них (етап 3 плану).
- Немає файлу в Figma й каталогу компонентів (Storybook).
